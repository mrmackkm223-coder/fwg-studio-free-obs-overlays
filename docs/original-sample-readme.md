# GRIDLINE · Free stream sample

Two useful PNGs from the GRIDLINE visual direction: a 1920 × 1080 Starting
Soon screen and a 640 × 160 About panel (designed for 320 × 80 display).
The sample is unwatermarked and uses generic text so you can use it as is.

Unzip first. In OBS, create or select a scene, add an Image source, and
choose starting.png. Use a 1920 × 1080 canvas or scale the source to fit.
Upload about.png where your streaming platform supports a custom panel.
These PNGs are static. The free sample does not include editable SVGs,
name personalization, webcam frames, or the local animated browser scene.

Official OBS setup: https://obsproject.com/kb/image-sources
Checked October 6, 2026. OBS Image sources support PNG.
